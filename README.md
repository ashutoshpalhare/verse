# AP VERSE
> AP's Visual Universe

AP VERSE is a premium, cinematic personal portrait archive designed to celebrate visual moments in a private, high-performance environment.

## The Core Experience
- **Cinematic Discovery**: Automatic local image detection from `/public/images/`.
- **Private Universe**: Completely local-first architecture with persistent metadata.
- **Futuristic Interface**: OKLCH-based theming engine with obsidian-grade dark modes.
- **Gestural UX**: Mobile-first fluid interactions and cinematic splash screens.

## Technical Foundation
- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4 + OKLCH
- **Store**: Zustand with LocalStorage Persistence
- **Animations**: Framer Motion
- **Discovery**: Vite Asset Globbing

## Initialization
1. `bun install`
2. Populate `public/images/` with your visual history.
3. `bun dev`
